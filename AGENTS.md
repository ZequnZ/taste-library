# Taste Library project instructions

Read `llm.txt`, `docs/authoring.md`, and `skills/taste-library/SKILL.md` for design and collection work.

The repository contains a Vite gallery using standard HTML, CSS, and JavaScript. `collection.json` is authoritative metadata. Confirmed entries and demonstrations remain separate. Request user approval before adding entries or confirmed preferences.

Run `npm run validate`, `npm test`, and `npm run build` after implementation. Browser verification uses Playwright and checks actual interactions and responsive overflow. Keep verification output in gitignored directories.

The user performs commits and pushes personally. Keep source attribution, original context, and reuse permissions with collected material. Technical identifiers retain their original spelling.
